EXEMPLES VALIDÉS :
- Question : Quel est le chiffre d'affaires total ?
  Intention : TOTAL_CA
  SQL validé : SELECT SUM(f.Chiffre_Affaires) AS Chiffre_Affaires_Total
     FROM Fact_Ventes f;
  Explication : Le chiffre d'affaires total est la somme de Fact_Ventes.Chiffre_Affaires.
- Question : Quel est le CA par région ?
  Intention : CA_PAR_REGION
  SQL validé : SELECT
         r.Region,
         SUM(f.Chiffre_Affaires) AS Chiffre_Affaires
     FROM Fact_Ventes f
     INNER JOIN Dim_Region r
         ON f.Region_ID = r.Region_ID
     GROUP BY r.Region
     ORDER BY Chiffre_Affaires DESC;
  Explication : Le CA est agrégé par région via Dim_Region.
- Question : Quel est le CA par catégorie en 2025 ?
  Intention : CA_PAR_CATEGORIE_ANNEE
  SQL validé : SELECT
         p.Categorie,
         SUM(f.Chiffre_Affaires) AS Chiffre_Affaires
     FROM Fact_Ventes f
     INNER JOIN Dim_Produit p
         ON f.Produit_ID = p.Produit_ID
     INNER JOIN Dim_Date d
         ON f.Date_ID = d.Date_ID
     WHERE d.Annee = 2025
     GROUP BY p.Categorie
     ORDER BY Chiffre_Affaires DESC;
  Explication : Le CA est agrégé par catégorie et filtré sur l'année 2025.
- Question : Quel est le chiffre d'affaires total ?
  Intention : Calculer le chiffre d'affaires total
  SQL validé : 
    SELECT
        SUM(fv.Chiffre_Affaires) AS Chiffre_Affaires_Total
    FROM dbo.Fact_Ventes AS fv;
    
  Explication : La colonne Chiffre_Affaires est une mesure additive.
- Question : Quel est le chiffre d'affaires par région ?
  Intention : Agrégation du chiffre d'affaires par région
  SQL validé : 
    SELECT
        dr.Region,
        SUM(fv.Chiffre_Affaires) AS Chiffre_Affaires_Total
    FROM dbo.Fact_Ventes AS fv
    INNER JOIN dbo.Dim_Region AS dr
        ON fv.Region_ID = dr.Region_ID
    GROUP BY
        dr.Region
    ORDER BY
        Chiffre_Affaires_Total DESC;
    
  Explication : La table Fact_Ventes est reliée à Dim_Region par Region_ID.
